Server-side syntax highlighting powered by Syntect with inline styles (no external CSS required). Automatic code copy-to-clipboard buttons injected on all pages with code blocks. Language alias mapping for PowerShell, Nix, HCL/Terraform, Fish, and others. Uses base16-ocean.dark theme. Configurable theme support tracked separately as a planned improvement.
