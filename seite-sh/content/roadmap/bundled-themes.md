Ships with 11 bundled themes, listed by `seite theme list`. Since v0.21.0 they are split into 4 starters (default, docs, landing, and blank, a bare layout for designing your own) and a 7-theme gallery (minimal, dark, brutalist, bento, terminal, magazine, academic). Each theme includes full SEO meta, JSON-LD structured data, search integration, pagination, i18n support, and responsive design. Themes can be installed from URL (`seite theme install`), exported (`seite theme export`), or designed by your coding agent with `/seite theme <description>` (or `seite theme create "<description>"`).
