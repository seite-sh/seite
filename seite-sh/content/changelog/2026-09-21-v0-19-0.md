## Portable agent instructions

New sites now keep their generated project guidance in `AGENTS.md`, so multiple coding agents can share one canonical instruction file. `CLAUDE.md` contains only `@AGENTS.md` for Claude Code compatibility.

Running `seite upgrade` migrates existing `CLAUDE.md` guidance without losing custom content. Projects that already have both files keep their Claude-specific instructions while gaining exactly one canonical import.

Instruction migration is atomic, preserves file permissions, rejects invalid paths, and writes the new project version only after every upgrade succeeds. Skill-pack integrations now use the same canonical instructions and clean up legacy managed sections.
