## `seite upgrade` in workspaces

Running `seite upgrade` from a workspace root used to fail with "No seite.toml found in current directory". It now upgrades every site listed in `seite-workspace.toml`: the pending changes are shown grouped by site and applied after a single confirmation. `--site <name>` upgrades just one site, `--check` exits 1 if any site needs upgrading, and `--json` reports each site's changes under `data.sites`. Running it inside a site's directory still upgrades only that site.
