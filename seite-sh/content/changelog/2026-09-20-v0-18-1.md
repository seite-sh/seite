## Password access documentation

- Clarified that files under `static/private/<group>/` are password protected only when `[access]` is enabled. Without it, they remain publicly reachable under `/static/private/<group>/`.
- Corrected the internal password-update documentation to reflect that a failed password upload invalidates existing sessions while leaving the previous password active until the command is rerun.
- Normalized paths shown by `seite access groups` so its output matches the paths enforced by the Cloudflare Worker.
