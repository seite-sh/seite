A maintenance release. Upgrade with `seite self-update`; no `seite upgrade` step is needed, and the generated site is unchanged.

## Dependencies

- **Docker image:** built with Rust 1.98 (was 1.88). The minimum Rust version for `cargo install seite` stays 1.88.
- Updated `signal-hook` 0.4 (`seite serve` shutdown), `indexmap` 2.14.2 and `unicode-normalization` 0.1.26.
