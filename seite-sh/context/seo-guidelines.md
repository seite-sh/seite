# SEO Guidelines for seite Content

## Content Length

- **Standard blog post**: 1,500-2,500 words
- **Guides / tutorials**: 2,000-3,500 words
- **Changelog / updates**: 200-500 words
- Quality over quantity — every section should provide genuine value

## Keyword Optimization

### Placement
Primary keyword must appear in:
- H1 headline
- First 100 words
- At least 2 H2 subheadings
- Meta title (first 60 characters)
- Meta description
- URL slug

### Density
- Primary keyword: 1-2% naturally integrated
- Secondary keywords: sprinkled throughout
- Never force keywords — write for developers first

## Content Structure

### Heading Hierarchy
- One H1 per page with primary keyword
- 4-7 H2 sections for standard articles
- H3s nested under H2s (never skip levels)
- Subheading every 300-400 words

### Readability
- Short paragraphs (2-4 sentences)
- Active voice preferred
- Include code examples and commands where relevant
- Use lists for sequential or multiple items

## Internal Linking

- 3-5 internal links per article minimum
- Use descriptive anchor text (not "click here")
- Always reference `context/internal-links-map.md` for link targets
- Link to relevant docs pages from blog content

## Meta Elements

### Title
- 50-60 characters with primary keyword
- Format: `[Topic]: [Benefit] | seite`

### Description
- 150-160 characters with keyword and CTA
- Clear value proposition

### URL Slug
- Include primary keyword
- 3-5 words, lowercase, hyphens
- No stop words unless necessary

## seite-Specific SEO Notes

seite automatically handles:
- Canonical URLs
- Open Graph + Twitter Cards
- JSON-LD structured data (BlogPosting, Article, WebSite)
- Sitemap with xhtml:link alternates
- robots.txt with AI crawler management
- llms.txt and llms-full.txt
- Markdown alternate links

When writing content, focus on the content quality. seite handles the technical SEO.

## Checklist

- [ ] Primary keyword in H1, first 100 words, meta title, description, URL
- [ ] 3-5 internal links with descriptive anchors
- [ ] Code examples included where relevant
- [ ] Content provides unique value vs competitors
- [ ] Active voice, short paragraphs, scannable structure
